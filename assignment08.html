Foreground vs. Background Images

Most images on a web page are foreground images. They are part of the page's content, so they are added in the HTML with the img tag. A photo in a gallery or a picture that goes with an article is a foreground image.

Background images work differently. They are decoration, not content, so they are added with CSS instead of HTML. The image behind this page is set on the body element in the site's stylesheet, so every page that links to that stylesheet gets the same background. It uses no-repeat and center center so it appears once, centered, and background-size: cover stretches it to fill the whole window.

Keeping Text Readable

A busy background placed directly behind text makes it hard to read and pulls attention away from photos. To avoid that, the background image is used only on the body. The container that holds the text has its own background color, which is white at 92% opacity, written as rgba(255, 255, 255, 0.92). The background image shows around the edges, but the text sits on a calm, high-contrast surface.

Styling the Navigation Links

The menu above is an unordered list inside a nav element. The links are styled with the descendant selector nav li a, which means "an a element that is inside an li that is inside a nav." This affects only the menu links, not links in the main text. Each menu link has a small arrow icon as a background image, placed with background-position: right center and no-repeat. Extra padding on the right side leaves room for it. Move your mouse over a link to see the a:hover rollover effect.
